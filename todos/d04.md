## 🔧 Implementation details

### Folder structure
```
/client/src
  /api        axios.js, auth.js, bookings.js, vehicles.js
  /context    AuthContext.jsx
  /components SlotPicker, BookingTable, ProtectedRoute
  /pages      Login, BookVehicle, MyBookings, AdminBookings
  App.jsx, main.jsx
```

### Axios instance
- `baseURL: import.meta.env.VITE_API_URL || 'http://localhost:3000/api/v1'`.
- Request interceptor: attach `Authorization: Bearer <token>` from AuthContext/localStorage.
- Response interceptor: on `401` clear auth + redirect to `/login`.

### AuthContext
- Holds `{ token, user }`, persisted in localStorage.
- `login(token, user)`, `logout()`. Exposes `user.role` for guards.

### Route guards
- `<ProtectedRoute roles={['admin','super_admin']}>` → redirect to `/login` if no token, to `/` if role not allowed.
- Routes: `/login` (public), `/book` + `/my-bookings` (employee+), `/admin/bookings` (admin+).

### Login page (two-step)
1. Step 1: email input → `POST /auth/request-otp` → always show "OTP sent, check your inbox" (in dev, read it from the server console).
2. Step 2: 6-digit code input → `POST /auth/verify-otp` → on success store token+user, route by role (employee → `/book`, admin → `/admin/bookings`).
3. On 401 → "Invalid or expired code."

### Book a Vehicle page
1. Ant `DatePicker` → on change call `GET /vehicles/available?date=`.
2. Vehicle selector (only vehicles returned).
3. Slot selector (only that vehicle's `available_slots`).
4. Form: destination, purpose, passenger_count, contact_number.
5. Submit → `POST /bookings`:
   - 201 → success toast with booking ID, redirect to My Bookings.
   - **409 → error toast "This slot is no longer available," refresh availability.**

### My Bookings page
- `GET /bookings` (server scopes to own) → Ant Table with status badges (color per status).
- Cancel button shown only when `status = 'pending'` → `PATCH /:id/status {status:'cancelled'}`.

### Admin Bookings page
- `GET /bookings` (all) + filters: date range, vehicle, status.
- Row actions: Approve / Reject (only on `pending`) → `PATCH /:id/status`.
- Refresh table after each action.

### NPM (frontend)
`react, react-router-dom, antd, axios, dayjs` (`@ant-design/charts` deferred to MVP dashboard).

2. Try to book the same vehicle/date/slot → blocked with 409 toast.

4. Log back in as employee → booking now shows `approved`.
