## 🔧 Implementation details

### Theme (`ConfigProvider`)
- Wrap the app (already wrapped in `main.jsx`) with theme tokens:
  ```js
  theme={{ token: { colorPrimary: '#1d4ed8', borderRadius: 10, fontSize: 14 },
           components: { Layout: { headerBg: '#1e3a8a' } } }}
  ```
- Define a shared status palette used by `StatusBadge` and calendar later:
  `pending=gold, approved=green, rejected=red, completed=blue, cancelled=default, maintenance=orange`.

### Layout shells (`client/src/layouts/`)
- `EmployeeLayout.jsx` — content area + fixed **bottom tab bar** (AntD `Menu` or custom) with Book / My Bookings / Notifications / Profile; mobile max-width container centered on desktop.
- `AdminLayout.jsx` — AntD `Layout.Sider` sidebar (Dashboard / Bookings / Vehicles / Calendar / Users / Reports / Settings) + header with user + Feedback + Logout.
- Pick the shell by role in `App.jsx` (`isAdmin(role)` → AdminLayout, else EmployeeLayout). Login stays shell-less.

### Shared components (`client/src/components/`)
- `StatusBadge` — `<Tag color={STATUS_COLOR[status]}>`; single source for status colors.
- `VehicleCard` — photo (fallback to a car emoji tile if `image_url` empty), name, `🪑 seats · ⚙️ transmission`, `📍 parking`, availability badge, optional "Nearest" tag, selectable (radio) for the wizard.
- `KPICard` — title, big value, sub-label, optional %-delta (green/red arrow).
- `BookingCard` — vehicle thumb, booking code, date/slot, vehicle·seats, `StatusBadge`, status-colored left border, optional action button + chevron.

### Stub pages (so nav resolves now, built out later)
- Employee: `Notifications` (M5), `Profile` (M2) → simple "Coming soon" cards.
- Admin: `Dashboard` (M3), `Calendar` (M3), `Vehicles` (M4), `Users` (M4), `Reports` (M4), `Settings` → "Coming soon" cards. Keep `Bookings` = existing AdminBookings, `Feedback` page as built.

### Backend — vehicle fields
- `006_add_vehicle_fields.sql`:
  ```sql
  ALTER TABLE vehicles
    ADD COLUMN image_url VARCHAR(255) NULL,
    ADD COLUMN transmission ENUM('auto','manual') NOT NULL DEFAULT 'auto',
    ADD COLUMN parking_location VARCHAR(100) NULL;
  ```
- Include the new columns in `vehicleController` availability output and any vehicle reads.

### Seed images (self-contained, no internet/upload)
- Drop 2–3 simple car SVGs under `client/public/vehicles/` (e.g. `sedan.svg`, `suv.svg`, `van.svg`).
- Update seed (or a one-off UPDATE) so each vehicle has `image_url` (e.g. `/vehicles/suv.svg`), `transmission`, `parking_location` (e.g. `Parking B1`).
- `VehicleCard` reads `image_url`; falls back to a 🚗 tile if null.
