## 🔧 Implementation details

### Migration 007 — roles (order matters)
```sql
-- Convert existing super_admins BEFORE narrowing the enum, or they'd become ''.
UPDATE users SET role = 'admin' WHERE role = 'super_admin';
ALTER TABLE users
  MODIFY COLUMN role ENUM('employee','driver','admin') NOT NULL DEFAULT 'employee';
```
(The migrate runner tracks applied files in `schema_migrations`, so this runs once.)

### Migration 008 — vehicle ↔ driver
```sql
ALTER TABLE vehicles
  ADD COLUMN driver_user_id INT NULL,
  ADD CONSTRAINT fk_vehicle_driver FOREIGN KEY (driver_user_id) REFERENCES users(user_id);
```
