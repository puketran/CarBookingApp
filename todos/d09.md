# Day 9 — No-Show Strikes & Monthly Booking Block

> From `docs/rules.md`: *"if 3 times not use car then block user; admin section to control times."*
>
> **Decisions:** driver marks the no-show · block = can't create bookings for the **rest of the current month** (not a login ban) · admin screen views counts + unblocks.
> **Interpretation:** no-shows counted per **calendar month**; the **3rd no-show in a month** sets `booking_blocked_until = last day of that month`; auto-clears next month; admin can unblock early.

---

## 🎯 Goal (achieve by end of day)

A driver can mark an approved trip as **no-show**; the 3rd no-show in a calendar month blocks that user from booking until month-end (booking attempts → 403); an **admin Users screen** shows each user's this-month no-show count + blocked-until and can **unblock**.

**Runnable at end of day:** driver marks 3 no-shows for the employee → employee's next `POST /bookings` → 403 (blocked until <date>) → admin unblocks → employee can book again.

## 🔧 Implementation details

### Migrations
- `010`: `ALTER TABLE bookings MODIFY COLUMN status ENUM('pending','approved','rejected','completed','cancelled','no_show') NOT NULL DEFAULT 'pending';`
- `011`: `ALTER TABLE users ADD COLUMN booking_blocked_until DATE NULL;`

### Driver no-show + strike logic (`driverController`)
- Add `no_show` to the allowed actions; require booking status `approved` → set `status='no_show'`.
- After setting, recount and maybe block the booking's owner:
  ```sql
  SELECT COUNT(*) n FROM bookings
   WHERE user_id = ? AND status = 'no_show'
     AND YEAR(booking_date) = YEAR(CURDATE()) AND MONTH(booking_date) = MONTH(CURDATE());
  ```
  if `n >= 3`: `UPDATE users SET booking_blocked_until = LAST_DAY(CURDATE()) WHERE user_id = ?`.
- Validator: add `no_show` to the action enum.

### Booking guard (`bookingController.create`)
- Before insert: `SELECT booking_blocked_until FROM users WHERE user_id = ?`; if set and `>= CURDATE()` →
  `403 { error: 'USER_BLOCKED', message: 'Too many no-shows this month — booking is blocked until <date>.' }`.

### Admin users (`adminController` + `routes/admin.js`, `requireRole('admin')`)
- `GET /admin/users`:
  ```sql
  SELECT u.user_id, u.name, u.email, u.department, u.role, u.is_active, u.booking_blocked_until,
         (SELECT COUNT(*) FROM bookings b WHERE b.user_id = u.user_id AND b.status='no_show'
            AND YEAR(b.booking_date)=YEAR(CURDATE()) AND MONTH(b.booking_date)=MONTH(CURDATE())) AS noshow_this_month
  FROM users u ORDER BY u.user_id;
  ```
- `PATCH /admin/users/:id` body `{ booking_blocked_until: null }` → clear the block (unblock). (Room to add role/active edits in M4.)
- Mount `/admin/users` (note: keep distinct from the future super-admin add-user; this is the management list).
