## 🔧 Implementation details

### Backend (`GET /calendar?month=YYYY-MM`, admin)
- For each active vehicle and each day in the month, compute:
  - `booked` = count of bookings (pending/approved/completed) that day,
  - `slots_left` = 5 − booked,
  - `maintenance` = vehicle.status === 'maintenance' (whole-month flag for now).
- Return a compact structure, e.g. `{ days: [...], vehicles: [{ vehicle_id, name, cells: { 'YYYY-MM-DD': {booked, slots_left} } }] }`.
- One or two grouped queries (count bookings GROUP BY vehicle_id, booking_date for the month), assembled in JS.

### Frontend (`pages/AdminCalendar.jsx`)
- Render a scrollable table: first column = vehicle (name + seats), one column per day.
- Cell color by state (use `STATUS_HEX`); label per the counts. Maintenance → orange "Maint.".
- Header: month label + `< >` nav + (Calendar | Timeline) segmented.
- Cell click → `Drawer` calling `GET /bookings?vehicle_id=&date=` (admin) for the detail list.

### Notes
- Reuse the admin `GET /bookings` filters for the cell detail rather than a new endpoint.
- Keep it readable on desktop; horizontal scroll is fine for a full month.
