## 🔧 Implementation details

### Backend — vehicles (`vehicleController` + routes, admin)
- `GET /vehicles` (all, incl. inactive) with driver name; `POST` create; `PUT/:id` update (name, plate, capacity, driver_user_id, status, image_url, transmission, parking_location); `DELETE/:id` soft-delete (status → `maintenance`/inactive — pick + document; "active" excluded from availability already).
- Driver assignment writes `driver_user_id`.

### Backend — users (`adminController`)
- Extend `PATCH /admin/users/:id` to accept `{ role, is_active, booking_blocked_until }` (validate role ∈ employee/driver/admin).
- `POST /admin/users` `{ email, name, department, role }` → insert; this is how admins add admins/drivers (replaces the dropped super-admin-only endpoint).

### Backend — export (`exportController`, admin)
- `exceljs` workbook per report; set `Content-Type` + `Content-Disposition` filename.
  - **bookings:** Date | Vehicle | Employee | Department | Destination | Purpose | Slot | Status (filters: from,to,vehicle_id,department,status).
  - **utilisation:** Vehicle | Total Slots | Used Slots | Utilisation % (reuse dashboard utilisation logic).
  - **monthly:** Month | Total Bookings | Total Hours.

### Frontend
- `pages/AdminVehicles.jsx`: `Table` + `Modal` form (Add/Edit), driver `Select` (from `/admin/users?role=driver` or all), status, image (path select among seeded SVGs), transmission, parking.
- Extend `AdminUsers.jsx`: inline role `Select`, active toggle, "Add user" modal.
- `pages/AdminReports.jsx`: `RangePicker` + buttons → `window.open`/blob download of each export URL (with auth — use axios blob + save).

### Notes
- Export downloads need the JWT; fetch as blob via axios then trigger a client-side download (anchor) rather than a raw link.
- Keep vehicle image as a path picker (seeded SVGs); upload is out of scope.
