- In `services/mailer.js`, when `NODE_ENV === 'production'` (or `RESEND_API_KEY` set): send via Resend with `from: EMAIL_FROM`. Keep the console log for dev. Same `send({to,subject,text})` signature — no call-site changes.
- Add `resend` dependency.

### Deploy (Railway)
- Backend service: build/start `npm start`; env vars set in Railway (use the **internal** `DATABASE_URL` now that app + DB are both on Railway).
- Frontend: build `client` and serve statically — simplest is a second Railway static service, or have the backend serve `client/dist` and SPA-fallback to `index.html`. Pick + document.
- CORS: lock to the deployed frontend origin.
- Point the frontend's API base at the deployed backend (env-driven `VITE_API_URL` or same-origin if backend serves the static build).
