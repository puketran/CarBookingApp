>

## 🔧 Implementation details

### Settings
- `014`: `CREATE TABLE settings (skey VARCHAR(50) PRIMARY KEY, svalue VARCHAR(100))` + `INSERT IGNORE` the 4 defaults.
- `services/settings.js`: `getSettings()` → numbers merged over DEFAULTS; `setSettings(obj)` upserts.
- `adminController`: `getSettings`/`updateSettings`; routes `GET/PATCH /admin/settings` (admin).

### Availability for the picker
- `GET /vehicles/active` → active vehicles (id, name, capacity, driver_name, image_url, transmission, parking_location).
- `GET /vehicles/:id/availability` (auth): from Monday of the current week through `booking_weeks*7` days. For each day: `{ date, dow, past, open, takenSlots[] }` from bookings (pending/approved). Returns `{ weeks, days }`.

### Booking guards (`bookingController.create`, order)
1. no-show block (existing) → 403 `USER_BLOCKED`.
2. **weekly limit:** `COUNT(*) WHERE user_id=? AND status IN ('pending','approved','completed') AND YEARWEEK(booking_date,1)=YEARWEEK(?,1)`; if `>= bookings_per_week` → 403 `WEEKLY_LIMIT`.
3. invalid slot → 422; conflict → 409.

### No-show ban (`driverController.applyStrike`)
- Use `noshow_limit`; on reaching it set `booking_blocked_until = DATE_ADD(CURDATE(), INTERVAL ban_months MONTH)`; notify.

### Frontend wizard (`BookVehicle.jsx`)
- Steps: **Select car** (cards from `/vehicles/active`) → **Select day** (week grid from `/vehicles/:id/availability`) → **Select slot** (5 blocks colored from the chosen day's takenSlots) → **Details** (form, requester name + department pre-filled from `useAuth`, editable).
- Colors: grey/disabled = can't book (past or full/taken), green = open, blue = selected.
- Submit handles 201 / 409 / 403 (USER_BLOCKED, WEEKLY_LIMIT) with clear toasts.

### My Bookings
- Default tab → `upcoming`. Add a "Group by day" `Switch`; when on, group cards under date headers (sorted).

### Admin Settings (`pages/AdminSettings.jsx`)
- Replace `/admin/settings` stub: form with 4 `InputNumber`s (booking window weeks, bookings/week, no-show limit, ban months); load `GET /admin/settings`, save `PATCH`.

### UI/UX
- Ensure the wizard fits the mobile shell: content scrolls, week grid uses a 7-col responsive layout, no horizontal overflow, bottom-nav padding respected.
