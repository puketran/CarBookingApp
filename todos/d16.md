# Day 16 — Password Auth (OTP → register / forgot only)

> Auth model change: **login is email + password**. OTP is now used **only** to register (set a first password) or reset a forgotten one.
>
> **Decisions:** hashing = Node **scrypt** (built-in, salted) · **open self-registration** (any email can register via OTP → creates an `employee` account) · change-password while logged in needs **no current password**.

---

## 🎯 Goal (achieve by end of day)

Users log in with email + password. "Set / forgot password" sends an OTP (any email) → enter code + new password → account created (if new) or password reset → logged in. A logged-in user can change their password from Profile. Seeded accounts get a default dev password so login works immediately.

**Runnable at end of day:** log in with a seeded account's password; use "Forgot password" to OTP-reset; register a brand-new email via OTP; change password from Profile.

## 🔧 Implementation details

### Migration 016
`ALTER TABLE users ADD COLUMN password_hash VARCHAR(255) NULL;`

### Password service (scrypt)
- `hashPassword(pw)` → `${salt}:${scrypt(pw,salt,64)}` (salt = 16 random bytes hex).
- `verifyPassword(pw, stored)` → timing-safe compare; false if no stored hash.

### Auth endpoints (`authController` + `routes/auth.js`)
- `login`: lookup active user by email; `verifyPassword`; else `401 INVALID_CREDENTIALS`; issue JWT.
- `request-otp`: generate 6-digit, store SHA-256 hash (existing `otp` service), `mailer.send` (console in dev). Always sends (open register), rate-limited 5/email/hr; generic 200.
- `set-password`: validate newest unused/unexpired OTP (attempts < 5) → on match: if user exists update `password_hash`, else INSERT `(email, role='employee', password_hash)`; mark OTP used; issue JWT + return user. Password min 8.
- `password` (PATCH, `requireAuth`): set `password_hash` for `req.user` (no current pw). Min 8.
- Drop the `verify-otp` route/handler.

### Seed
- `ensurePasswords()`: set `hashPassword('password123')` on any user with `password_hash IS NULL`. Log the default. (Runs after migrate.)

### Frontend
- `Login.jsx`: three modes —
  - **login**: email + password → `POST /auth/login` → store + route by role.
  - **request** ("Set / forgot password"): email → `POST /auth/request-otp` → go to reset.
  - **reset**: 6-digit code + new password → `POST /auth/set-password` → store + route.
- `Profile.jsx`: add a **Change password** card → `PATCH /auth/password { password }`.

### Docs
- CLAUDE.md: auth = email+password; OTP = register/forgot only; note the seeded default password.
