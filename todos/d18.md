## 🔧 Implementation details

### `src/i18n.jsx`
- `DICT = { en, zh, vi }` keyed by dotted keys (e.g. `nav.book`, `login.signIn`).
- `translate(lang, key, params)` → `DICT[lang][key] ?? DICT.en[key] ?? key`, with `{param}` interpolation.
- `LanguageProvider` holds `lang` (default `en`, from localStorage), exposes `{ lang, setLang, t }`. `useLang()` hook.
- Export `ANTD_LOCALES = { en: en_US, zh: zh_CN, vi: vi_VN }`.

### `main.jsx`
- Wrap with `LanguageProvider`; an inner `Root` reads `useLang()` and renders `ConfigProvider theme + locale={ANTD_LOCALES[lang]}`; set `dayjs.locale(lang)` on change.

### Components/pages
- Replace literal strings with `t('...')`. Keep logic identical.
- `LanguageSelector`: small `Select` (EN / 中文 / Tiếng Việt) → `setLang`; placed in headers + Login card.
- `StatusBadge`: map status → `t('status.<status>')`.
